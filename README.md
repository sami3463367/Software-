# Software Company — product index

Our first product is **Moss & Ember**, a cozy 3D farm sim.

- 🌱 **Game code + docs:** [`moss-and-ember/`](moss-and-ember/README.md)
  (Godot 4.7 project — slice 0.1 is playable in the browser)
- 🎨 **Art direction references:** [`concepts/`](concepts/) (Style A: bright cartoon)

## How we build

The game is developed in an AI-agent sandbox with full GitHub access:
the engine (Godot 4.7.2) is compiled from source in the sandbox, the game is
built and self-tested there, and a browser build is served live for play
testing on any device.
